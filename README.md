# Портфолио Данила Рябова

Портфолио технического партнёра для бизнеса с опытом личной разработки и руководства небольшой командой. Акцент на веб-сервисах, мобильных продуктах, интеграциях и автоматизации.

Адаптивный статический сайт на русском языке. HTML, CSS и JavaScript без сборщика и сторонних JavaScript-зависимостей.

Адрес сайта: https://danil-koding.github.io/danilkoding/

Репозиторий: https://github.com/danil-koding/danilkoding

Публикация: GitHub Pages через `.github/workflows/pages.yml`. Workflow публикует только `portfolio/dist` после изменений в `main`.

## Локальный запуск

```sh
npm run dev
```

Открыть `http://127.0.0.1:4173`. Нужны Python 3 и, для запуска через npm, Node.js. Напрямую: `python3 -m http.server 4173 --bind 127.0.0.1 --directory portfolio/dist`.

## Редактирование

- `portfolio/dist/index.html` — основные тексты, контакты, опыт.
- `portfolio/dist/styles.css` — оформление и адаптивная сетка.
- `portfolio/dist/projects.js` — все 17 проектов, фильтры, личный вклад и ссылки.
- `portfolio/dist/hero.js` — три варианта первого экрана (`?hero=partner`, `?hero=team`, `?hero=product`). Сравнение: `hero-options.html`.
- `portfolio/dist/app.js` — фильтрация, модальные окна, мобильная навигация, копирование почты.
- `portfolio/dist/assets` — локальные изображения и PDF-резюме.

Проверка JavaScript: `npm run check`. Для размещения на любом статическом хостинге достаточно содержимого `portfolio/dist`.

Проверено в Chromium на ширинах 320, 375, 390, 768, 1024 и 1440 px: фильтры (17 проектов, 14 мобильных, 3 веб), открытие и закрытие карточек, Escape и возврат фокуса, мобильное меню, копирование почты, доступность локальных изображений и PDF. Ошибок JavaScript не обнаружено.

## Контент

Источники: предоставленное резюме и 16 опубликованных кейсов [IT Production](https://it-production.dev/projects/), проверенных 17 ноября 2026 года. Drimly добавлен как отдельный проект из резюме. Личный вклад подробно описан только там, где он указан в резюме; остальные кейсы атрибутированы совместной работе с командой студии. Показатели из резюме не пересчитываются автоматически с течением времени.

Контакты ведут непосредственно в Telegram и почту; сайт не собирает заявки и не использует аналитику. Фотография взята из резюме. Шрифт Golos Text загружается с Google Fonts; при недоступности используется системный sans-serif. Восстановлено светлое оформление с зелёными акцентами и позиционированием технического партнёра для бизнеса. Обложки Cooperator (ex-CoShop) и Drimly предоставлены пользователем; исходные PNG размещены без изменения изображения и отображаются целиком.

Предыдущее размещение Sites отключено 17 ноября 2026 года: все пути отвечают HTTP 410, ассеты портфолио больше не развёртываются. Запись проекта в интерфейсе Sites остаётся. Для GitHub Pages в Settings → Pages используется источник GitHub Actions.

В избранном шесть проектов: Drimly, Cooperator, ХМБ Банк, Мясорубка Доставка, Мясорубка Учёт, Run & Done. GlobalPO исключён по уточнению автора. Карточки раскрывают задачу бизнеса, решение, роль и результат; обложки остаются в сетке проектов, внутри модальных окон удалены. Исходный PDF-резюме сохранён без редактирования.
